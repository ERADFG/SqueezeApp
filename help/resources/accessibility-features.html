Accessibility features on InteractInk

Article 3 of 6 in Resources

InteractInk aims to work well with assistive technology and to be usable regardless of how you navigate the site.

  • The interface is built to work with screen readers, with meaningful labels on buttons and controls.
  • Both light and dark themes are available, along with alternate accent colors, from your display settings — useful if you're sensitive to bright screens or need higher contrast.
  • Video playback includes standard captioning support where captions have been provided.

If you run into something that doesn't work well with the assistive tools you use, let us know through the Contact page — accessibility issues are treated as real bugs, not nice-to-haves.
